## Проект:

Виджет банковских операций клиента.

## Функции:

1. реализована функция get_mask_card_number, маскировки номера банковской карты  и 
функция get_mask_account, маскировки номера банковского счета. 
2. реализована функция mask_account_card, которая возвращает строку с замаскированным номером, и функция get_date,
которая возвращает строку с датой в формате (ДД.ММ.ГГГГ).
3. реализована функция operations_transform, которая принимает на вход путь до JSON-файла из директории data (из json
    в данные python) и возвращает список словарей с данными о финансовых транзакциях в виде списка.
4. реализован декоратор my_decorator, для логирования корректности работы функций в файл mylog.txt если 
указан в параметрах декоратора или в консоль если не указан.
5. реализована функция exchange_currency, выводящая стоимость из транзакций с конвертированием в рубли (с 
применением API c https://apilayer.com)
6. реализована функция read_func_CSV по преобразованию данных файла CSV в список словарей.
7. реализована функция read_func_Excel по преобразованию данных файла EXCEL в список словарей.
8. реализованы функции  process_bank_search и process_bank_operations в модуле filter.py
для фильтрации списков словарей
9. реализована функция main для взаимодействия с пользователем и вывода списка операций по запросу
